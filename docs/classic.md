# Ходьба без RL

Новая демонстрационная реализация: диагональная рысь `leg_1 + leg_4` / `leg_2 + leg_3`. Номер ноги взят из URDF, а не из условной таблицы подключения сервоприводов. Плечо остаётся в положении опорной стойки. Бедро и колено решают небольшое смещение центра цилиндра стопы по корпусным `Y` (вперёд/назад) и `Z` (подъём) через кинематику калиброванного URDF. В фазе опоры стопа проходит в противоположном направлении без подъёма.

Тесты сверяют исходные центры стоп со снимком стойки, диагональные фазы и попадание целей в диапазоны для полного цикла. Это **геометрия**, а не проверка контактов, устойчивости или фактической скорости. Повороты, боковые команды, регуляция баланса и переход на физический робот не входят в эту ветку.
