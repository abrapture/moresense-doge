# RL V1: архивный эксперимент и запуск политики

PPO через RSL-RL в Isaac Lab / Newton (MuJoCo Warp): исходно 256 сред, затем `model_200.pt` продолжен на 512 средах ещё 800 итераций. Сеть имеет три скрытых слоя по 128 нейронов и ELU. [`checkpoints/v1_999/model_999.pt`](../checkpoints/v1_999/model_999.pt) — снимок для PPO; [`trained_policy_999/policy.pt`](../trained_policy_999/policy.pt) — TorchScript с нормализацией для инференса. Один файл не заменяет другой.

Вход — 45 чисел: 3 гироскопа, 3 направления гравитации, 12 отклонений суставов от стойки, 12 скоростей суставов, 12 предыдущих ограниченных действий, `[vx, vy, yaw]`. Политика обучена задавать `vy` по оси корпуса `+Y` или `−Y`, а не боковой ход и разворот. Выход — 12 поправок к стойке: ограничение до ±1, масштаб 0,25 рад, затем диапазоны суставов. Период политики 20 мс.

## Сохранённая оценка

В [архивном прого́не Newton](../verification/walk_eval_999_seed123_8s.json) по 8 с на команду, seed 123:

| +0,15 | +0,139 | 0 |

На обратном ходе заметен разворот (примерно 84° за первые 3 с по сохранённой [трассе](../verification/walk_trace_999_partial.log)); на нулевой команде — дрейф около 7 см за 8 с. Скорость в системе корпуса скрывает уход с курса. Эти числа взяты из архива, не из новой демонстрации.

## Локальная демонстрация на CPU

Установите [PyTorch](https://docs.pytorch.org/get-started/locally/) в отдельное Python-окружение и используйте профиль `rl-manual` или `rl-autonomous`. Загрузчик принимает только вложенный экспорт V1, сверяет SHA-256, порядок суставов и связанную калибровку. Не загружайте чужие файлы TorchScript или checkpoint без проверки происхождения.

В демонстрации показания корпуса идеализированы, а следующее положение суставов равно последней ограниченной цели. При нулевой команде демонстратор задаёт опорную стойку и сбрасывает предыдущие действия вместо вызова сети. Это **не Newton, не обучение и не проверка на роботе**.

## Физическая симуляция V1

При наличии совместимого [окружения Newton/CUDA](simulation.md) разместите репозиторий в папке `moresense_doge` и запускайте из её родительской директории:

```sh
python -m moresense_doge.training.walk_eval \
  --checkpoint moresense_doge/checkpoints/v1_999/model_999.pt \
  --device cuda:0 --seconds 8 --seed 123 --report walk_eval_local.json
```

В новой реконструкции этот GPU-прогон не повторялся. Используйте отдельный путь для отчёта, не меняйте сохранённые файлы.
