# Без RL · управление оператором

```sh
python3 -m doge_control classic-manual --ticks 40
printf '%s\n' '{"tick":0,"forward_mps":0.08}' '{"tick":4,"stop":true}' | python3 -m doge_control classic-manual --commands - --ticks 6
```

Оператор задаёт продольную скорость по локальной `+Y` через JSONL; отрицательное значение задаёт ход назад. Источник принимает от −0,15 до +0,15 м/с. Без обновления спустя 10 отсчётов задаётся стойка. `stop: true` прекращает движение до нового запуска. `--commands -` читает сценарий со стандартного ввода до EOF, это не управление джойстиком в реальном времени.

Цели выдаёт [кинематическая рысь](../classic.md). График контактов и устойчивость не рассчитываются.
