# Без RL · автономный сценарий

```sh
python3 -m doge_control classic-autonomous --ticks 24
```

Маршрут: 0,5 с вперёд, пауза 0,2 с, ещё 0,6 с вперёд. Без препятствия и с актуальными данными затем остаётся стойка. В стандартном примере [виртуальный передний датчик](../../examples/front_range.jsonl) обнаруживает препятствие на отсчёте 16; движение не возобновляется, даже когда путь в журнале освобождается.

`--range FILE` задаёт свой JSONL с `tick` и `distance_m`; один отсчёт занимает 20 мс модельного времени. Нет первого замера, замер старше или равен 100 мс либо расстояние не больше 0,35 м — остановка до следующего запуска. Здесь нет карты, слежения за человеком или подключения к реальному датчику.
