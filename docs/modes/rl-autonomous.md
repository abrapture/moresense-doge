# RL V1 · автономный сценарий

В Python-окружении с PyTorch:

```sh
python -m doge_control rl-autonomous --ticks 24
```

Планировщик задаёт два коротких движения вперёд с паузой между ними, а вычисление суставных целей поручено [V1](../rl-v1.md). В [стандартном журнале дальности](../../examples/front_range.jsonl) препятствие появляется на отсчёте 16. Политика не получает дальность и не отвечает за выбор маршрута: препятствие или потеря свежих данных прекращают выдачу команды движения выше по цепочке. Повороты и объезд не реализованы.

`--range FILE` заменяет журнал переднего датчика. Остановка здесь означает нулевую команду и переход целей к архивной стойке в предварительном просмотре, а не снятие питания или E-stop.
