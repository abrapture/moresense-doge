# RL V1 · управление оператором

В Python-окружении с PyTorch:

```sh
python -m doge_control rl-manual --ticks 40
```

Тот же [операторский журнал](../../examples/operator.jsonl), что и без RL: прямой ход, потеря команды, обратный ход, `stop`. `--commands FILE` заменяет журнал; `--commands -` принимает JSONL со стандартного ввода до EOF. Скорость по `Y` подаётся в сохранённую [политику V1](../rl-v1.md), а тайм-аут и остановка обрабатываются вне нейросети.

Показания и время синтетические, вывод — цели суставов, а не подтверждение ходьбы робота.
